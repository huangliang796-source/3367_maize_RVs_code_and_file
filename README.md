# 3367_maize_RVs_code_and_file
This repository contains the codes and data files for the 3,367 maize whole-genome sequencing (WGS) project.

The related article can be cited as: 
Huang et al., Deep sequencing of 3,367 maize genomes uncovers substantial contribution to agronomic traits, Cell (2026), [https://doi.org/10.1016/j.cell.2026.09.063](https://doi.org/10.1016/j.cell.2026.09.063) .

If you have any questions, please feel free to contact me at huangliang796@cau.edu.cn.

Information on the maize inbred lines and their phenotypic values is provided in supplementary tables of the associated publication. 
Genotype data for these inbred lines are available through the MaizeWorld database: https://ngdc.cncb.ac.cn/maizeworld/
