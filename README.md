# 3367_maize_RVs_code_and_file
This repository contains the codes and data files for the 3,367 maize whole-genome sequencing (WGS) project.

If you have any questions, please feel free to contact me at huangliang796@cau.edu.cn.

Information on the maize inbred lines and their phenotypic values is provided in Table S1A of the associated publication. 
Genotype data for these inbred lines are available through the MaizeWorld database: https://ngdc.cncb.ac.cn/maizeworld/
